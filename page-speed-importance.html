What is Page Speed?

Page speed is the time your website takes to load content on a single page. With speed optimization services, you can load page content faster, bringing in more traffic. Developers may call this page load time, which means the same — the time your page takes to display all its content, or how long your web browser takes to receive the first byte of information. Technically, page speed is calculated in different ways. The simple breakdown of various elements is:

  • Time to First byte (TTFB)
  • Time to Interactive (TTI)
  • First contentful paint (FCP)
  • Load time

How To Measure Your Site Speed?

For starters, you can use tools like PageSpeed Insights, GT Metrix, and WebPageTest. These sites help you in knowing the core issues behind slow-loading pages. They have unique features that let you test in different regions, browsers, and devices.

An Ideal Page Speed Load Time

According to research done by Geoff Kenyon in 2011, the ideal website speed must be any of these as mentioned below:

  • When a site loads in 5 seconds, it is faster than 25% of the web
  • When a site loads in 2.9 seconds, it is faster than 50% of the web
  • When a site loads in 1.7 seconds, it is faster than 75% of the web
  • When a site loads in 0.8 seconds, it is faster than 94% of the web

And a recent research done by Backlinko came down with conclusions:

The average page loading speed for a web page is 10.3 seconds on desktop and 27.3 seconds on mobile. Technically, any website takes more than 85% longer to load on a mobile device than on a desktop.
